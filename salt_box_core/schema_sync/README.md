# Модуль для работы с Git-репозиторием (JSON-схемы и sls-файлы)

## Работа с Git-репозиторием

- `GitPython` для локального взаимодействия с репозиторием.
- Локальная копия репозитория в поддиректории проекта (задается в `config`).

## Реализовано

- Ручка синхронизации схем
  - clone/pull репозитория
  - поиск всех JSON-файлов в репозитории
  - загрузка схем в базу данных, если они отсутствуют
  - обновление схем в базе данных, если изменился хэш последнего коммита
  - удаление схем из базы данных, если их нет в репозитории
- Ручка получения списка схем
- Ручка получения схемы по `id`
